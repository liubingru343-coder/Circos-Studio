# Circos Studio

**交互式生物信息学弦图关系可视化系统**

Circos Studio 是一款基于 R Shiny 开发的交互式生物信息学可视化工具，主要用于样本—物种关系和基因—通路关系的可视化分析。系统通过 Circos 弦图展示不同节点之间的关联及其权重，支持数据导入、图形参数调整、节点筛选、关系查询和可视化结果导出。

项目旨在提供一个操作直观、交互灵活、易于使用的生物信息学关系可视化平台。

## 二、核心功能

### 1. 双模式关系可视化

系统提供两种关系分析模式：

- **样本—物种模式（Sample–Species）：** 展示不同样本与物种之间的关联关系。
- **基因—通路模式（Gene–Pathway）：** 展示不同基因与生物学通路之间的关联关系。

用户可以根据分析需求切换关系模式。

### 2. 数据导入与处理

支持导入 CSV、XLSX 和 XLS 格式的数据文件。

输入数据需要包含以下三列：

| 字段 | 含义 |
|---|---|
| Source | 来源节点 |
| Target | 目标节点 |
| Value | 连接权重，必须为大于 0 的数值 |

系统支持对重复的 Source–Target 组合进行合并，并对权重进行求和。缺失、非数值和无效权重记录将被过滤。

未上传文件时，系统使用内置示例数据。

### 3. 交互式图形设置

用户可以通过左侧控制面板调整：

- 突出显示节点
- 最小连接权重
- 图形配色方案
- 连线透明度
- 节点标签显示状态
- 图表标题

同时支持恢复默认设置，方便进行不同参数下的图形比较。

### 4. 数据预览与关系查询

系统提供数据预览与关系明细表，展示来源节点、目标节点和连接权重。

用户可以通过表格排序和选择关系记录，查看对应的关系信息。

### 5. 图形导出

支持将生成的 Circos 弦图导出为：

- SVG 矢量图
- PNG 位图

方便用于学术论文、科研汇报和研究成果展示。

## 三、系统界面

系统采用左右分栏布局：

- 左侧：数据导入、关系模式选择及图形参数设置。
- 右侧：统计信息、Circos 弦图和数据预览。

通过交互式控制面板，用户可以实时调整可视化效果。

## 四、运行环境与技术架构

### 开发环境

- 操作系统：Windows
- R：建议使用 R 4.6.1
- 开发工具：RStudio
- 应用框架：Shiny

### 主要技术与依赖包

| 技术或程序包 | 主要用途 |
|---|---|
| R | 数据处理与程序运行 |
| Shiny | 交互式 Web 应用开发 |
| circlize | Circos 弦图绘制 |
| readxl | Excel 数据读取 |
| DT | 交互式数据表格 |
| svglite | SVG 图形输出 |

### 本地运行

1. 下载并解压项目仓库。
2. 使用 RStudio 打开项目目录。
3. 安装所需依赖：

```r
install.packages(c(
  "shiny",
  "circlize",
  "readxl",
  "DT",
  "svglite"
))
```

4. 在 RStudio 中打开 `app.R`。
5. 点击 Run App，或在 R 控制台执行：

```r
shiny::runApp()
```

6. 浏览器将打开本地运行的应用页面。
