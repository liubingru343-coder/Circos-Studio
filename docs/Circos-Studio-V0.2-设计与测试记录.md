# Circos Studio V0.2 设计、实现与测试记录

## 升级目标
在保留 Shiny + circlize 架构的前提下，补齐双模式内置示例数据，增加关系表选中行到弦图节点高亮的联动，并优化绘图留白和导出设备管理。

## V0.2 变更
1. 新增 gene_data()，提供独立基因—通路示例数据。
2. 未上传文件时，input$mode 控制示例数据；上传文件后，上传数据优先。
3. 关系表按权重降序展示，选中一行后将 Source、Target 两端节点传递给弦图高亮逻辑。
4. 调整绘图上边距和标题位置，增加图形区域留白。
5. SVG、PNG 导出读取当前筛选和高亮状态，并在绘图后关闭图形设备。
